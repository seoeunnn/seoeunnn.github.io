LINE Seed Sans KR webfonts, downloaded unchanged from the official LINE Seed website.

- Regular: https://seed.line.me/src/fonts/LINESeedSansKR-Rg.woff2
- Bold: https://seed.line.me/src/fonts/LINESeedSansKR-Bd.woff2
- Publisher: https://seed.line.me/index_kr.html
- License: SIL Open Font License 1.1; see OFL.txt (https://github.com/line/seed/blob/main/OFL.txt).

The official font server does not return a cross-origin access header. Local files are used so the preview does not silently fall back to a different typeface.
